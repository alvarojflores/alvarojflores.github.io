INVITACIÓN INTERACTIVA DE CUMPLEAÑOS
=====================================

ARCHIVOS
- index.html: estructura de la invitación.
- styles.css: diseño adaptable a celular y computadora.
- script.js: datos de la fiesta, mapa y envío de respuestas a WhatsApp.
- assets/homenajeado.jpg: coloca aquí la foto real del homenajeado.

PERSONALIZACIÓN
1. Abre script.js en un editor de texto.
2. Cambia los datos del objeto INVITATION:
   - honoreeName: nombre del homenajeado.
   - eventDate y eventTime: fecha y hora.
   - venueName y venueAddress: local y dirección.
   - hostName: nombre de quien invita.
   - whatsappNumber: número receptor con código de país, solo números.
     Ejemplo de formato para Nicaragua: 50588881234.
   - mapQuery: dirección o nombre exacto del local para el mapa.
3. Guarda la fotografía del homenajeado como assets/homenajeado.jpg.
   Se recomienda una foto vertical o cuadrada, de buena calidad.
4. Abre index.html en el navegador para probarlo.

ENVÍO POR WHATSAPP
Al enviar el formulario, se abre WhatsApp con el mensaje preparado. La persona
invitada debe pulsar "Enviar" dentro de WhatsApp. No se manda silenciosamente
ni se almacena información en un servidor.

PUBLICACIÓN
Para compartir la invitación mediante un enlace público, sube la carpeta a un
servicio de alojamiento web estático (por ejemplo, GitHub Pages, Netlify o
similar). Si solo envías index.html, los estilos, scripts y foto deben viajar
junto con él en sus carpetas correspondientes.
